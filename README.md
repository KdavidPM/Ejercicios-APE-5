## Introducción

El manejo de ficheros en Java permite crear, almacenar y administrar información de manera permanente. En esta actividad se desarrollan ejercicios prácticos sobre la creación, escritura y eliminación de archivos de texto, utilizando diferentes clases y métodos propios del lenguaje Java.
